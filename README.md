
# Task Manager

A modern, responsive Task Manager web application built using HTML, CSS, and JavaScript.

This project helps users organize daily tasks, track progress, and stay productive.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed
- Filter tasks by All, Active, and Completed
- Light and Dark Mode toggle
- Save tasks automatically using localStorage
- Track completed and remaining tasks
- Dynamic progress bar
- Responsive design
- Modern UI with Lucide icons

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser localStorage
- Lucide Icons

## How to Use

1. Enter a task in the input field.
2. Click "Add Task" or press Enter.
3. Check the box to mark a task as completed.
4. Use the Edit or Delete icons to manage tasks.
5. Filter tasks using All, Active, or Completed.
6. Switch between Light and Dark Mode.
7. Track your progress using the statistics dashboard.

## Installation

1. Clone this repository:

   git clone https://github.com/AMBAYUSH/task-manager.git

2. Open the task-manager folder.

3. Open index.html in your browser.
